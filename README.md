# Project_Eterna
This project was born from a desire to preserve memories beyond loss. It offers a digital space where stories, emotions, and legacies live on—allowing loved ones to be remembered, honored, and felt. A tribute to connection, healing, and the timeless power of remembrance.

## Current Development: DOGSNIFF Phase 1

We are currently developing **DOGSNIFF Phase 1**, which integrates Google's Gemini API for advanced language model capabilities. This phase provides the foundation for memory analysis, text generation, and conversational AI features.

### Quick Start

1. Install dependencies: `pip install -r requirements.txt`
2. Configure your Gemini API key in `.env` (see `.env.example`)
3. Run the demo: `python main.py`

For detailed documentation, see [DOGSNIFF.md](DOGSNIFF.md).

## Project Phases

- **Phase 1 (Current)**: Gemini API Integration - Text analysis and generation capabilities
- **Phase 2**: Memory storage and retrieval system
- **Phase 3**: Multi-modal support (images, audio, video)
- **Phase 4**: User interface development
- **Phase 5**: Full ecosystem integration
